# HURL Debian Builds

HURL HTTP Requests is an lightweight, terminal-based alternative for GUI API/REST HTTP clients like Insomnia, Bruno and Postman.

## Source

The source : `https://github.com/Orange-OpenSource/hurl`

We are currently building against the tag `v8.1.0`

## Download

Currently the HURL build is only available for Ubuntu 26.04 LTS

### Ubuntu 26.04 LTS

https://github.com/debuggerboy/hurl-debian-builds/releases/download/8.1.0/hurl-8.1.0-ubuntu-26.04-amd64.tar.bz2

## > [!WARNING]
> Currently this build is only supporting Ubuntu 26.04 only. please use it at your own risk.
